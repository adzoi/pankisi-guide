# Pankisi Valley Guide

Login-protected guide to Pankisi Valley, Georgia: an interactive map of guesthouses, food, sights, trails and services, plus Kist and Georgian cuisine.

## Run

    npm install
    PORT=3457 npm start

Open http://localhost:3457 and create an account. Accounts are stored in `data/users.json` (git-ignored); sessions are in memory. Use a real database and HTTPS before deploying.

## Content notes

Place locations are village-level approximations. Photos are from Wikimedia Commons; authors and licences are in `credits.json` and the page footer.
